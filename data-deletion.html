Data Deletion Instructions

Last updated: August 2026

This application is an internal automation tool that publishes content to accounts owned by Core Decor. It does not collect, store, or process personal data belonging to any third party, and there is no user account system associated with this app.

Because no third-party personal data is collected, there is no third-party data to delete. If you believe this app has stored information about you in error, contact the address on file with the associated Meta developer account and it will be investigated and removed if found.
