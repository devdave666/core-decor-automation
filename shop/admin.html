Connect your GitHub token

Create a token scoped to only this repository, with Contents: Read and write permission and nothing else:

  1. Go to github.com/settings/personal-access-tokens/new
  2. Repository access → Only select repositories → core-decor-automation
  3. Permissions → Repository permissions → Contents: Read and write (leave everything else as No access)
  4. Generate, copy the token, and paste it below

This token is stored ONLY in this browser's local storage. It is never sent anywhere except directly to api.github.com. Don't use this page on a shared or public computer, and revoke the token on GitHub if this device is ever lost.
